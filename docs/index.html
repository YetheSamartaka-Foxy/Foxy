Install Foxy

Foxy is a mod updater and launcher for Arma 3, Total War: WARHAMMER III, Arma Reforger, and other games. The same program is the desktop app and the command line.

Install with one command (run it again to update):

# Windows, in PowerShell
irm https://yethesamartaka-foxy.github.io/Foxy/install.ps1 | iex

# Linux and macOS, in a terminal
curl -fsSL https://yethesamartaka-foxy.github.io/Foxy/install.sh | sh

The command downloads the newest release, checks its SHA-256, and installs it. A current-user install needs no administrator permission. Saved repositories, settings, and databases stay on the computer. Downloaded mods stay in the folders you chose.

Longer notes, including Proton and Wine, are in the User Guide.

Windows 10 and 11

irm https://yethesamartaka-foxy.github.io/Foxy/install.ps1 | iex

That puts Foxy in the Start menu and in Settings > Apps. The files go to %LOCALAPPDATA%\Programs\Foxy. A running Foxy is closed and then started again.

When Foxy is already installed for all users, the same command updates that copy, and Windows asks for administrator permission. It leaves a separate current-user copy alone when both exist.

To download it by hand, open the release page and run Foxy-<version>-setup.exe. The setup can install for you or for every user of the PC. Delete all existing Foxy user data starts unchecked and asks before it removes settings and databases. Mod folders are kept either way.

Foxy's Windows setup is the x64 installer. It also runs on ARM PCs. It requires 64-bit Windows.

Linux (x86_64 and ARM64)

curl -fsSL https://yethesamartaka-foxy.github.io/Foxy/install.sh | sh

That installs Foxy for the current user in ~/.local/opt/foxy, adds a foxy command, and adds Foxy to the applications menu. It needs no root. The command picks Foxy-<version>-linux-x86_64-installer.sh or Foxy-<version>-linux-aarch64-installer.sh for this computer. When a release has no installer for this processor, it stops and leaves the computer unchanged.

When the only existing install is the system copy in /opt/foxy, the command updates that copy and asks for administrator permission.

By hand, from the release page:

chmod +x Foxy-<version>-linux-x86_64-installer.sh
./Foxy-<version>-linux-x86_64-installer.sh --prefix="$HOME/.local/opt/foxy"
sudo ./Foxy-<version>-linux-x86_64-installer.sh

The first is a current-user install. The second is a system install in /opt/foxy. Use one of them. On ARM64, use the linux-aarch64 installer when the release includes it.

macOS 11 or newer

curl -fsSL https://yethesamartaka-foxy.github.io/Foxy/install.sh | sh

That puts Foxy.app in ~/Applications (the Applications folder in your home folder) when the release includes a disk image for this Mac. Published releases include Foxy-<version>-macos-arm64.dmg for Apple Silicon. The command checks the download's SHA-256.

To download it by hand, open that disk image from the release page and drag Foxy to Applications.

macOS may say it could not verify Foxy. Open System Settings, go to Privacy & Security, and allow Foxy. This macOS build is experimental. Steam Workshop needs libsteam_api.dylib next to the Foxy executable inside the app.

Update or remove

  • Installed with the command? Run the same command again to update.
    • Windows: remove Foxy in Settings > Apps > Installed apps. The uninstaller can also delete Foxy's settings and databases if you check that box. Mod folders stay.
    • Linux and macOS: curl -fsSL https://yethesamartaka-foxy.github.io/Foxy/install.sh | sh -s -- --uninstall
  • Linux system install? Update by running the command again, or run the .sh installer with sudo. Remove it with sudo ./Foxy-<version>-linux-<arch>-installer.sh --uninstall --prefix=/opt/foxy.
  • Downloaded by hand? Run the newest setup, Linux installer, or disk image. On Windows and Linux, Foxy's own update check uses those same installers and keeps your saved data.
  • To also remove settings, delete the config folder in the table below. That folder holds settings, databases, caches, and logs. It does not hold your mod downloads.

Where Foxy keeps its files

WindowsLinuxmacOS
Installed by the command%LOCALAPPDATA%\Programs\Foxy~/.local/opt/foxy~/Applications/Foxy.app
System installC:\Program Files\Foxy/opt/foxy
Settings and databases%APPDATA%\Foxy~/.config/Foxy~/Library/Application Support/Foxy

On Linux, the settings folder follows $XDG_CONFIG_HOME when that is an absolute path.

Set FOXY_INSTALL_REPO to owner/name only for a repository you trust. The command installs what that repository publishes.
